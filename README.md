# 🐶🐱 Cat vs Dog Image Classifier

An end-to-end image classification system built using **EfficientNet** and **TensorFlow**, with GPU-accelerated training and a Streamlit-based inference app.

---

## Features

- Transfer learning using EfficientNet
- Optimized `tf.data` pipeline to handle corrupted images, I/O bottlenecks, and memory constraints
- Achieved **99%+ validation accuracy**
- Interactive Streamlit web app for real-time inference
- One-click launcher with automatic dependency setup
